# cosmo_ai_fit
本文提出一个三标量宇宙学有效场论框架，将暴涨后重热化、暗物质生成及辐射演化统一为同一动力学机制，并提供完整的可观测预测与统计检验路径。

📄 标题
基于三标量能量转移机制的宇宙学有效场论模型：从暴涨后重热化到结构形成的统一描述
🧠 摘要
本文提出一个基于有效场论的三标量宇宙学模型，其中主标量场 φ 通过衰变机制分别耦合至暗物质场 χ 与辐射/标准模型组分 H，从而统一描述宇宙从暴涨后重热化到结构形成的演化过程。该模型引入非平衡能量转移机制，在背景演化与线性扰动层面产生可观测修正。我们推导其宇宙学背景方程与扰动方程，并将其嵌入Boltzmann数值框架，以预测宇宙微波背景（CMB）与物质功率谱的偏离结构。同时建立似然函数与参数推断方法，为未来基于 Planck Collaboration 与 DESI 的观测数据提供统一检验框架。
📌 1. 引言
标准宇宙学模型 ΛCDM 在解释宇宙大尺度结构方面取得成功，但其暗物质与暗能量的微观起源仍未明确。同时，暴涨后重热化过程缺乏统一动力学描述。本文提出一种基于三标量场耦合的统一框架，将宇宙成分的生成过程描述为能量转移驱动的非平衡动力学系统。
